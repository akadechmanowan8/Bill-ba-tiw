# บิลค่าเหล้า ร้านป้าติ๋ว

เว็บแอปจดบิลเหล้าหงส์ทอง/โซดา แยกตามคน ติดตั้งบนหน้าจอมือถือได้ (PWA)

## วิธีอัปขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `bill-pa-tiw`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `manifest.webmanifest`, `sw.js`, โฟลเดอร์ `icons`) ไว้ที่ราก (root) ของ repo
3. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch` → Branch `main` / `(root)` → Save
4. รอ 1-2 นาที เปิด `https://<ชื่อ-github>.github.io/bill-pa-tiw/`

## ติดตั้งบนหน้าจอ
- iPhone (Safari): ปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม
- Android (Chrome): เมนู ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก

## เรื่องข้อมูล
ข้อมูลเก็บในเครื่องที่ใช้ (localStorage) ไม่ขึ้นเซิร์ฟเวอร์ แต่ละเครื่องจึงแยกกัน
ควรกด "⬇ สำรองข้อมูล" เป็นระยะ และใช้ "⬆ นำเข้า" เพื่อย้ายข้อมูลไปเครื่องอื่น
(หากเปิดผ่านแอปที่ติดตั้ง กับเปิดผ่านเบราว์เซอร์ อาจเป็นที่เก็บคนละชุดบน iPhone ให้นำเข้าไฟล์สำรองอีกครั้ง)
